# 🚀 Popular Platforms UI Clones

Welcome to my **UI Clones** repository! This project contains responsive and visually stunning frontend clones of three major platforms. It was built to practice modern web development, styling, and layout techniques.

## 📂 Projects Included

### 1. 🛒 Amazon UI Clone
A fully responsive clone of the Amazon homepage.
- **Key Features:** Navigation bar with search functionality, product grid layout, sidebar navigation, and a footer section.
- **Technologies:** HTML, CSS

### 2. 🍿 Netflix UI Clone
A sleek and dark-themed clone of the Netflix landing page.
- **Key Features:** Hero section with a background banner, email subscription input, FAQ accordion, and responsive row layouts for movie categories.
- **Technologies:** HTML, CSS

### 3. 🐦 Twitter (X) UI Clone
A minimalist and functional clone of the Twitter web interface.
- **Key Features:** Left sidebar navigation, central tweet feed with post creation UI, and a right sidebar for trending topics and suggestions.
- **Technologies:** HTML, CSS

## 🛠️ Tech Stack
- **Structure:** HTML5
- **Styling:** CSS3 (Flexbox, Grid, Media Queries)

## 💡 Why this project?
I built these clones to:
- Deepen my understanding of complex UI layouts (Flexbox & CSS Grid).
- Practice writing clean, maintainable, and semantic HTML/CSS.
- Enhance my skills in making applications fully responsive across different screen sizes.

## 🚀 How to Run Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/hiteshraj786/ui-clone.git
   ```
2. Navigate to the specific clone folder (e.g., `cd amazon-ui-clone`).
3. Open the `index.html` file in your browser or use an extension like **Live Server** in VS Code.
